# No one sits / gallery revision 03
Freestanding, floor-connected initial structure inside a white gallery. Rapier dynamic active bodies and fixed dormant assemblies. Procedurally generated socket-linked part layouts, mode selection with success/failure feedback, staggered docking. External CC0 studio_small_09 HDRI and wood_table_001 PBR texture maps from Poly Haven, local fallbacks; texture fetch and actual GPU render remain unverified. Approximate colliders and static-fixed overlap remain limitations. No physical load-bearing engineering model, no claim of photorealism. Three.js MIT; Rapier Apache-2.0.
