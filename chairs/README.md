# No one sits / physics prototype 02
420 desktop / 180 mobile assemblies. Rapier 0.17.3 WebAssembly, zero gravity, compound colliders built from actual chair primitive dimensions. Fixed anchors and resting assemblies; active chairs and separated components are dynamic rigid bodies, with CCD, contact friction, and force-based steering. Six subassemblies can detach and rejoin in one of four layouts (standard, radial, ladder, split-fin). After convergence the exact solved local poses become one fixed compound; no position teleport on arrival. Target selection remains a stochastic occupancy graph, not a structural engineering solver. Failed destinations reroute; dense initial poses may intersect, fixed-fixed contact does not resolve, and active contacts are approximate. No cross-chair part exchange in this revision. Lighting: outdoor HDRI Urban Street 03 by Andreas Mischok / Poly Haven (CC0), fallback procedural environment; PBR materials, wood/stone bump, rounded chair edges, GTAO desktop, directional shadows. Three.js MIT; Rapier Apache-2.0. All simulation local, external static CDN and HDR dependencies. Runtime validation is required; no claim of photorealism.
