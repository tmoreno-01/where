# No one sits — live prototype
A standalone Three.js WebGL artwork, using procedural 3D furniture and a residential facade. 12 geometry variants, six independently rendered chair subassemblies per chair, plus upholstery on selected variants. Desktop 760 chairs, mobile 360. The persistent occupancy graph selects exposed chairs, checks support paths, reserves destination sites, and exchanges components between compatible chair types. A regional stochastic director and local disturbance influence assembly choices. This is a graph-based animated assembly, not a rigid-body collision solver; chair geometry may interpenetrate and paths are not collision-free. Models and materials are procedurally authored, not photographic scans. No backend. Three.js is MIT licensed. GPU/visual performance needs testing in real browsers before production.
