# No one sits / seamless studio revision 04
The scene contains only the chair sculpture, a white ground plane and white distance fog; no walls or ceiling. Local PMREM photographic-style softbox illumination, multiple shadow sources on desktop, GTAO, optional Poly Haven CC0 wood_table_001 maps with procedural fallbacks, bevelled beams and direction-scaled wood UVs. 420 desktop and 180 mobile assemblies. Rapier active dynamic compound bodies and independent loose parts, fixed resting assemblies. Paired compatible chairs can physically exchange back/leg subassemblies, keeping part identity, colour, scale and original rigid body. Directional construction fronts and previous-visit scoring augment adaptive strategy selection. Actual arrival poses are retained. No guarantee of contact-free routes, true structural load bearing, or photorealism; fixed initial intersections remain possible. This is not a path-traced renderer. Visual and GPU runtime validation still required. Three.js MIT, Rapier Apache-2.0.
